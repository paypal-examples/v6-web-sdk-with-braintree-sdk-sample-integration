PayPal Edit Saved Payment Flow (Edit FI)

This is the recommended integration pattern for Braintree merchants that let a returning buyer view and change the PayPal funding instrument (card, bank account, etc.) behind an already-saved PayPal account, inline during checkout.

Step 1: Save a PayPal account

Edit Saved Payment needs an existing vaulted PayPal account to edit, so first save one the same way the Billing Agreements demo does.

Step 2: Edit the saved payment method

Click the saved payment method below to open PayPal and change the underlying funding instrument.
